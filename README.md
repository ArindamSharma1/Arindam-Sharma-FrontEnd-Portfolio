# Arindam Sharma - Full Stack Portfolio

A premium, modern portfolio website showcasing expertise across Cyber Security, Full Stack Development, and DevOps.

## Tech Stack
- **Frontend**: Vite, React, Tailwind CSS, Framer Motion
- **Icons**: Lucide React
- **Animations**: Framer Motion, Lenis (Smooth Scroll)
- **Deployment**: Vercel

## Key Features
- **Three Tracks**: Dedicated focus on Cyber Security, Full Stack Dev, and DevOps.
- **Project Showcase**: Problem-solution focused descriptions with live links.
- **Responsive Design**: Fully optimized for mobile and desktop.
- **Premium Aesthetics**: Dark theme with smooth micro-animations.

## Getting Started

1. Clone the repository
2. Install dependencies:
   ```bash
   npm install
   ```
3. Set up environment variables:
   Copy `.env.example` to `.env` and fill in your EmailJS credentials.
4. Run the development server:
   ```bash
   npm run dev
   ```
